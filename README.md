## 🙋‍♀️ 關於我

我是 Maggie，在一家運動用品 OEM 廠負責日本線業務。

每天的工作就是在日本客戶和工廠之間來回：陪客戶開發新品、追打樣、盯交期、算報價，出了品質問題就一起找原因。英文和日文是我的日常工具，我會看客戶切換語言，把客戶的需求翻成工廠聽得懂的話，再把工廠的回覆整理成客戶看得懂的答案。

這份工作教會我最重要的一件事：**只要覺得哪裡怪怪的，就不要輕易放過。** 一個尺寸、一個日期、一句「應該沒問題」，我都習慣多問一句「真的嗎？」。很多麻煩就是這樣提早攔下來的。

## 🧩 我的回覆 SOP：追問到底

公司資訊不外流是原則，但思考方式可以分享。每次回覆客戶，我都照這幾步走：

1. **先站到客戶的位置想**：客戶真正想知道的是什麼？拿到答案之後，他們要做什麼決定？
2. **把內部回覆當成拼圖**：各部門給的資訊，一塊一塊拼成客戶要的答案。
3. **缺的那一塊，一個一個問清楚**：拼到一半發現少了一塊或對不起來，就回頭去問，不靠猜。
4. **力求一次回覆到位**：讓客戶不用再追問第二次，是我對自己的要求。
