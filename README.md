## 關於我

我是 Maggie，在一家運動用品 OEM 廠負責日本線業務。

每天的工作就是在日本客戶和工廠之間來回：陪客戶開發新品、追打樣、盯交期、算報價，出了品質問題就一起找原因。英文和日文是我的日常工具，看客戶切換語言，也常常要把客戶的需求翻譯成工廠聽得懂的話。

這份工作教會我最重要的一件事：**只要覺得哪裡怪怪的，就不要輕易放過。** 一個尺寸、一個日期、一句「應該沒問題」，我都習慣多問一句「真的嗎？」。很多麻煩就是這樣提早攔下來的。

最近開始用 Claude Code 摸索程式，這個 GitHub 就是我的練習場。

- 🌏 語言：中文、English、日本語
- 🏭 專長：新品開發溝通、打樣與交期管理、報價、品質問題處理、廠內協調
- 🌱 正在學：Claude Code
